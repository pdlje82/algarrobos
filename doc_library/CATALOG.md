Companion images, alternative formats and asset metadata are counted within their parent research entries. The catalog, rename log and archived overview are additional metadata/history files.

Built for the Climate + Environment Career Transition context: understand real restoration work, develop an Almeria pilot, explore land stewardship and funding, and identify useful engineering, software and monitoring skills.

## Filename convention

`GROUP-NNN - Project or Place - Plain-language Content - Official Reference or Date.ext`

IDs are permanent references. Number within each group; allocate the next unused number and never recycle an ID. English descriptions make browsing easier; official place names and contract references remain recognizable. ASCII filenames avoid accent and sync compatibility issues. Dates appear only when supported by the document; a year in an official reference is not necessarily a publication date. The filename describes content; technical and lifecycle tags belong in the catalog rather than in an overloaded filename.
