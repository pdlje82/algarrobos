# Restoration Engineering & Environmental Project Library — Master Catalog

_Last updated: 9 October 2026_

This is the living master index for the Climate + Environment Career Transition project.  
Its purpose is not only to list restoration projects, but to make the collected documents searchable by:

1. **project / case study**
2. **technical domain**
3. **project lifecycle / professional function**
4. **career-learning value**
5. **coverage gaps**

A single document can have several tags.

---

# 1. Tagging system

# 7. What the library is already good for

The current library can already be used to study the professional chain:

**baseline diagnosis → hydrology / geology / ecology → restoration design → procurement → construction / planting → works supervision → environmental monitoring → financing / compliance**

This makes the collection especially useful for understanding:

- what environmental and civil engineering consultancies are actually asked to do;
- which specialist disciplines collaborate on restoration projects;
- which studies and datasets are required;
- how ecological objectives become drawings, quantities, budgets and contracts;
- how public administrations assess technical offers;
- how implementation is supervised and reported;
- how restoration is connected to EU/PRTR funding and measurable milestones.

For the career-transition objective, the most important current gap is the **digital monitoring layer**:

**Earth observation + GIS + remote sensing + sensors + environmental data engineering + automated monitoring / MRV.**

That is likely to be one of the areas where an engineering/software/ML background can add the most value.
