# Whole-plant botanical portraits

Created with built-in `image_gen` on 28 October 2026. All 16 original transparent
RGBA PNGs are 1254 × 1254 pixels and ship locally with the frontend.
The [manifest](manifest.json) contains the exact prompts, source files, hashes,
dimensions, growth-form descriptions and botanical reference links.

The checklist displays these representative mature plants. The paired viewer
retains the original botanical detail drawings, fitting both views initially
and offering an independent original-size view for each image.

Whole forms were reviewed for crown shape, basal branching, palm/clump versus
woody shrub habit, and foliage/flower characteristics against each plant’s
linked botanical references. They are representative AI illustrations, not
site-specific growth predictions or drawings at one biological scale.
Esparto is shown in foliage state, Ephedra in female form, and Tamarix is a
genus-level tree-form example. Original detail files were not replaced.
